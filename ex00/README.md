# Personal Portfolio

A responsive personal portfolio website built from scratch with HTML, CSS, and JavaScript, without frameworks, templates, or UI libraries.

## Sections
- Header with navigation bar
- About Me (with photo)
- Skills (grid)
- Projects (Projects 00-03, plus this portfolio)
- Hobbies
- Contact form
- Footer

## Features
- **Theme switcher:** a button toggles between light and dark mode.
  Clicking the button fires a `click` event, the JavaScript callback toggles
  the `dark` class on `<body>`, and the CSS rule `body.dark` changes the colors.
- **Responsive layout:** built with Flexbox, CSS Grid, and media queries.
  On screens 600px wide or less, the grids become one column and the header stacks vertically.

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (ES6)
- Git & GitHub
